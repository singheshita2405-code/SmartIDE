Before installing SmartIDE, ensure your system meets the minimum requirements to guarantee a smooth development experience.

Component Minimum Recommended

CPU 2 Cores, 2.0 GHz 4+ Cores, 3.0+ GHz

Installation via CLI

For power users, we recommend using our official CLI tool to manage your installation.

Terminal bash 
# Download and install the CLI
curl -fsSL https://smartide.dev/install.sh | bash

# Initialize your workspace
smartide init --template web-fullstack

# Start the development server
smartide start
