# SmartIDE Design System — Peach & White Desktop Theme

## 1. Overview
SmartIDE Peach & White is a high-clarity, calming aesthetic engineered specifically for developers. It eliminates dark-neon fatigue and harsh blue lights in favor of warm ivory backgrounds, soothing peach accents, and crisp typography.

## 2. Core Color Palette
- **Primary Accent:** `#ff7836` (Vibrant Peach)
- **Primary Gradient:** `linear-gradient(135deg, #d64508, #ff7836)`
- **Secondary Peach:** `#ffa574`, `#ffcfb2`, `#ffe4d2`
- **Background Primary:** `#ffffff` (Pure White)
- **Background Soft:** `#fffdfb` (Warm Ivory)
- **Background Panels:** `#fff6ee` (Soft Peach Ivory)
- **Text Dark (Espresso):** `#2b1810`
- **Text Medium (Terracotta):** `#613c2c`
- **Text Light (Taupe):** `#946956`
- **Borders & Dividers:** `rgba(255, 120, 54, 0.16)` to `rgba(255, 120, 54, 0.35)`

## 3. Desktop IDE Interface
- **Window Titlebar:** Native traffic light controls (close, minimize, maximize), project breadcrumb, Run button.
- **Menu Bar:** `File`, `Edit`, `Selection`, `View`, `Run`, `Terminal`, `Help` with working dropdowns.
- **Activity Bar:** Vertical rail for Explorer, Search, Source Control, Peach AI, Settings.
- **File Explorer:** Dynamic workspace file tree with create (+), refresh, and delete (×).
- **Tabbed Editor:** Pure white background, peach tab highlights, line numbers gutter, and auto-indentation.
- **Terminal & Output:** Bottom drawer with real Python 3.14 script execution.
- **Status Bar:** Git branch (`main`), line/column position, UTF-8, Python 3.14.7 status.
