SmartIDE Documentation

Welcome to the SmartIDE guide. Learn how to install, configure, and code in the Peach & White desktop IDE.

rocket_launch Quick Tour

SmartIDE is a lightweight desktop IDE engineered for responsiveness. Built on a clean peach and white design system, it delivers instant startup, workspace file management, an integrated Python 3.14 runner, and real-time terminal output.

Python Sample • workspace/main.py
def greet(name: str): return f"✨ Welcome to SmartIDE, {name}!" if __name__ == "__main__": print(greet("Developer")) print("Desktop Environment initialized successfully.")

window Installing on Windows

Follow these quick steps to get SmartIDE up and running on Windows 10 or 11 (64-bit):

  1. Download SmartIDE-Setup-v2.4.1-x64.exe from the Downloads page.
  2. Double-click the downloaded setup file to launch the SmartIDE Setup Wizard.
  3. Choose your preferred installation directory and click Install.
  4. Launch SmartIDE from your Start Menu or Desktop shortcut.

desktop_mac Installing on macOS

SmartIDE is distributed as a Universal Apple Silicon & Intel package:

  1. Download SmartIDE-v2.4.1-Universal.dmg.
  2. Open the .dmg disk image.
  3. Drag the SmartIDE app bundle into your /Applications folder.
  4. Launch SmartIDE from Spotlight or Launchpad.

terminal Installing on Linux

For Debian, Ubuntu, and derivatives, run:

Bash
sudo dpkg -i smartide_2.4.1_amd64.deb sudo apt-get install -f # resolve any missing runtime libs

edit_note Tabbed Code Editor

The editor supports multi-file tabs, line numbers gutter, and auto-indentation. Open any file from the left Explorer sidebar to edit. Unsaved changes are marked with an orange indicator on the tab.

play_circle Code Runner & Integrated Terminal

Execute your Python files directly inside SmartIDE without leaving the application:

  • Click the top bar Run button or press F5.
  • Or type commands like python main.py in the bottom terminal prompt.
  • Output and stack traces appear instantly in the TERMINAL drawer.

Click the robot icon on the left Activity Bar to open the Peach AI drawer. You can request instant code explanations, syntax diagnostics, and boilerplate generation for functions and error handling.

help Frequently Asked Questions

Where are my files stored?

All files are saved inside the local workspace/ directory within your SmartIDE root directory.

Can I run SmartIDE without installing?

Yes! Simply navigate to the Web IDE to run SmartIDE directly inside modern web browsers.
