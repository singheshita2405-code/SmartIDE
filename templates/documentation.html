SmartIDE Documentation

Welcome to the SmartIDE guide. Learn how to install, configure, and code in the Peach & White desktop IDE.

rocket_launch Quick Tour

SmartIDE is a lightweight desktop IDE engineered for responsiveness. Built on a clean peach and white design system, it delivers instant startup, workspace file management, an integrated Python 3.14 runner, and real-time terminal output.

Python Sample • workspace/main.py
def greet(name: str): return f"✨ Welcome to SmartIDE, {name}!" if __name__ == "__main__": print(greet("Developer")) print("Desktop Environment initialized successfully.")

window Installing on Windows

Follow these quick steps to get SmartIDE up and running on Windows 10 or 11 (64-bit):

  1. Download SmartIDE-Setup-v2.4.1-x64.exe from the Downloads page.
  2. Double-click the downloaded setup file to launch the SmartIDE Setup Wizard.
  3. Choose your preferred installation directory and click Install.
  4. Launch SmartIDE from your Start Menu or Desktop shortcut.

desktop_mac Installing on macOS

SmartIDE is distributed as a Universal Apple Silicon & Intel package:

  1. Download SmartIDE-v2.4.1-Universal.dmg.
  2. Open the .dmg disk image.
  3. Drag the SmartIDE app bundle into your /Applications folder.
  4. Launch SmartIDE from Spotlight or Launchpad.

terminal Installing on Linux

For Debian, Ubuntu, and derivatives, run:

Bash
sudo dpkg -i smartide_2.4.1_amd64.deb sudo apt-get install -f # resolve any missing runtime libs

workspace_premium Centralized Workspace

SmartIDE combines multiple development tools into a single browser-based platform. Developers can write code, manage files, work with databases, preview applications, and deploy projects without switching between multiple software tools.

web Unified Platform

SmartIDE provides a zero-installation development environment that reduces setup complexity and enables users to start development immediately through a unified interface.

  • Single platform for development activities.
  • Reduced onboarding time for developers and students.
  • Accessible from modern web browsers.
  • Integrated development workflow.

storage Built-In Databases

SmartIDE includes integrated SQLite database support with SQLAlchemy ORM, allowing users to create, manage, and interact with databases directly inside the development environment.

Feature Description
SQLite Zero-configuration relational database support.
SQLAlchemy ORM layer for simplified database operations.
Embedded Environment Database setup without external installations.
Integrated Access Direct database interaction from SmartIDE.

preview Rapid Live Previews

SmartIDE provides instant visual feedback by displaying application changes in real time. Developers can quickly test and validate updates without repeatedly reloading or reconfiguring their projects.

code Monaco Editor

SmartIDE uses the Monaco Editor to provide a VS Code-style coding experience directly within the browser.

  • VS Code-grade editing environment.
  • Syntax highlighting support.
  • Code editing and navigation tools.
  • Live interaction with project files.

database Integrated SQL Console

The Integrated SQL Console enables developers to execute SQL queries, inspect tables, manage schemas, and interact directly with project databases without leaving SmartIDE.

help Frequently Asked Questions

Where are my files stored?

All files are saved inside the local workspace/ directory within your SmartIDE root directory.

Can I run SmartIDE without installing?

Yes! Simply navigate to the Web IDE to run SmartIDE directly inside modern web browsers.
